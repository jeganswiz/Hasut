Local development

Installation and setup

HASUT is a pnpm monorepo. Redis, Postgres/PostGIS, and MinIO run in Docker. The API, member web, and admin apps run on the host. Use pnpm, not npm, for workspace scripts.

Node 22.14+ pnpm 10.15+ Docker Compose v2 Generated 11 Sep 2026

Tool Version Why
Node.js 22.14.0 (.nvmrc), engines >=22.14.0 API, Next.js, scripts, Prisma

Docker Desktop / Engine Compose v2 Postgres 16 + PostGIS, Redis 7, MinIO

corepack enable corepack prepare pnpm@10.15.1 --activate

Quick start

From the repository root:

pnpm install pnpm dev:up

Platform wrappers if you prefer not to type pnpm:

OS Command
Windows PowerShell .\scripts\dev-up.ps1
macOS / Linux ./scripts/dev-up.sh

pnpm install generates the Prisma client (apps/api postinstall) and installs Husky hooks. pnpm dev:up copies .env.example to .env if missing, starts Docker data stores, migrates, seeds when needed, then starts API / web / admin.

Redis is Docker-only. Do not run a second Redis on the host port 6379.

Scripts

Root npm scripts (package.json)

Script What it does
pnpm dev:up One-command local stack. Entry: scripts/dev-up.mjs.
pnpm dev:down Stop API / web / admin on ports 3001 / 3000 / 3002.
pnpm dev:down --infra Also stop Docker Postgres, Redis, and MinIO.
pnpm infra:up Start Compose services postgres, redis, minio, minio-init.
pnpm infra:up:api Build and start the full Compose file, including the API container on 3001.
pnpm infra:down docker compose down for infra/compose/docker-compose.yml.
pnpm db:generate Prisma client generate.
pnpm db:migrate Create/apply migrations during later sprints (prisma migrate dev).
pnpm db:migrate:deploy Apply existing migrations (what dev:up uses).
pnpm db:seed Load configuration and demo neighborhood data.
pnpm test:scripts Node test runner on scripts/dev-stack.spec.mjs.
pnpm lint / typecheck / test / build Turborepo quality gates.
pnpm format Prettier write across the repo.

pnpm dev:up flags

Flag Meaning
--skip-seed Do not seed demo data.
--seed Re-run seed even if the bootstrap row already exists.
--infra-only Start Docker stores, migrate, seed; do not start host apps.
--skip-install Skip pnpm install even if node_modules is missing.

Files in scripts/

File Role
dev-up.mjs Kickoff orchestrator: env, install, Docker, migrate, seed, start apps, wait for health.
dev-down.mjs Stop host listeners. With --infra, stop Compose data stores.
dev-stack.mjs Shared helpers: ports, Compose, pnpm-on-Windows, health waits, process stop.
dev-stack.spec.mjs Flag parsing tests.
dev-up.ps1 Windows wrapper that requires pnpm, then runs pnpm dev:up.
dev-up.sh Unix wrapper for pnpm dev:up.

What dev:up does, in order:

.env from .env.example (if missing) → load env pnpm install (if node_modules missing) Start Docker Desktop if the daemon is down (Windows/macOS) Compose up: postgres, redis, minio, minio-init Wait until redis-cli PONG and pg_isready pnpm db:migrate:deploy Seed unless bootstrap row exists (or --skip-seed / --seed) If not --infra-only: start missing @hasut/api, @hasut/web, @hasut/admin wait http://127.0.0.1:3001/health/ready wait http://127.0.0.1:3000 and :3002 Ctrl+C stops host apps. Docker Redis stays up.
On Windows the stack invokes pnpm through Node + pnpm.cjs so spawn does not hit pnpm.cmd EINVAL issues.

Web and admin rewrite browser /api/* to the API origin (default http://127.0.0.1:3001). Socket.io cannot use that rewrite; realtime uses the API host that matches the page. Prefer 127.0.0.1 on Windows so Node does not hit IPv6 localhost.

Environment

Copy .env.example to a root .env. Never commit .env. pnpm dev:up creates it automatically. The API loads .env from apps/api and the repo root. Next.js loads the root .env in next.config.ts. Prisma needs DATABASE_URL in the process environment.

Required for the API

Variable Local example Notes
DATABASE_URL postgresql://hasut:hasut@localhost:5432/hasut?schema=public Required. Compose user/db hasut.

JWT_ACCESS_SECRET 32+ character local placeholder Required. Replace in any shared environment.
JWT_REFRESH_SECRET 32+ character local placeholder Required. Separate from the access secret.

Never commit secrets. Never log OTP values, refresh tokens, or exact member coordinates. Public APIs return approximate labels and distance buckets only.

Manual path

If you do not want the one-command script:

pnpm install cp .env.example .env pnpm infra:up pnpm db:migrate:deploy pnpm db:seed pnpm --filter @hasut/api dev pnpm --filter @hasut/web dev pnpm --filter @hasut/admin dev

Mobile is Expo SDK 57 (current Expo Go). On a physical phone, set Metro and the API to your PC LAN IPv4, then start Expo Go mode:

pnpm --filter @hasut/mobile exec expo start --go --lan

Compose file: infra/compose/docker-compose.yml (project name hasut). Full API in Docker after the lockfile exists: pnpm infra:up:api.

Demo login

Seed loads configuration plus a demo neighborhood (members, professionals, businesses, connections, chats, notifications). Local admin sign-in uses the bootstrap phone and console OTP.

OTP Enter 123456 after Send code / Continue
Web http://localhost:3000
Admin http://localhost:3002

OTP is stored hashed in Postgres (otp_challenges) and verified through OtpProvider. Identity verification is not skill verification.

Quality gates

pnpm lint pnpm format:check pnpm typecheck pnpm test pnpm test:scripts pnpm build

CI (.github/workflows/ci.yml) starts PostGIS 16 and Redis 7, applies migrations, and runs the same gates with NODE_ENV=test. Pre-commit runs lint-staged (Prettier + ESLint) via Husky.

Workspace apps: apps/api, apps/web, apps/admin, apps/mobile. Shared contracts live in packages/types, packages/validation, and packages/api-client (Axios). Do not add a second HTTP client in the apps.

Production rules

  • OTP_PROVIDER=console is forbidden when NODE_ENV=production.
  • MEDIA_STORAGE=memory is forbidden in production.
  • DEV_OTP_CODE must be empty in production.
  • Put JWT secrets, S3 keys, OTP vendor keys, and SENTRY_DSN in a secret manager — not in git.
  • Phase 1 is a modular monolith. Do not add microservices, billing, bookings, or marketplace checkout unless that phase is requested.

Troubleshooting

Symptom What to check
Unable to reach the HASUT API API on 3001, NEXT_PUBLIC_API_URL=http://127.0.0.1:3001, Docker Redis/Postgres healthy, CORS origin allowed.
Docker daemon not ready Start Docker Desktop. The script waits up to 120s on Windows/macOS.
Timed out waiting for Redis/Postgres docker compose -f infra/compose/docker-compose.yml ps. Port 5432 or 6379 already taken.
Prisma / migrate fails Root .env has DATABASE_URL. Use pnpm so the workspace filter runs.
Port already in use pnpm dev:down then retry. dev:down kills listeners on 3000, 3001, 3002.
npm run dev:up confusion Prefer pnpm dev:up. npm may run the root script but will not manage workspace filters correctly elsewhere.
